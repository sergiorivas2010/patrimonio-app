# Patrimonio v1.2.2 — Subcuentas reales y planes de ahorro

Esta versión corrige cómo la IA interpreta objetivos y subcuentas.

## Cambios
- La IA solo puede tratar como existentes las subcuentas incluidas en los datos actuales.
- Los objetivos personales no se convierten automáticamente en subcuentas.
- Una subcuenta puede tener varias finalidades.
- Se añade una finalidad opcional al crear una subcuenta.
- La subcuenta `1/2`, cuando existe, se recuerda como ahorro general que también puede cubrir pagos futuros como ChatGPT.
- La antigua regla «Aportación a ChatGPT» pasa a llamarse «Aportación habitual a la subcuenta principal».
- La IA puede analizar si conviene crear una nueva subcuenta para una futura inversión.
- Si propone una subcuenta nueva, debe indicar que todavía no existe y ofrecer opciones prudente, equilibrada y flexible.
- Ahorrar para invertir se diferencia de invertir realmente.
- La IA no crea ni mueve dinero sin confirmación.
